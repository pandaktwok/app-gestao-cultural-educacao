# Cores SCCS

## Paleta aprovada (extraída dos PDFs)
| Papel | Hex | Uso |
|---|---|---|
| Verde SCCS | `#005C35` | etiquetas, numeração de seção, linhas de seção, valores de destaque, barras, legenda de foto, rótulos |
| Vinho | `#9B1B1B` | TODOS os títulos e "Página N" |
| Vermelho SCCS | `#DF1225` | traço da capa, barra do destaque, topo de card "zero/alerta" |
| Grafite | `#2B2B2B` | texto corrido |
| Cinza médio / claro | `#555555` / `#777777` | subtítulos e descrições / observações |
| Filete | `#CFD8D1` | linhas de tabela, borda de card |
| Divisor de logos | `#C8C8C8` | linha vertical entre logos |
| Rodapé | `#333333` (texto), `#878787` (linha) | bloco institucional |

Vermelho sobre branco tem 4,9:1 de contraste: use em elementos grandes, barras e números grandes, nunca em texto pequeno. Verde e vinho passam de 8:1.

## Paleta complementar (aprovada em 29/09/2026, para slides, capas e infográficos)
| Nome | Hex | Contraste | Uso |
|---|---|---|---|
| Creme | `#F7F3EA` | verde 7,3:1, vinho 7,4:1, grafite 12,8:1 | fundo alternativo, painéis |
| Menta | `#E6EFE9` | verde 6,9:1 | faixas, zebra de tabela |
| Ouro escuro | `#8A6420` | 5,4:1 sobre branco | ornamento, números de destaque, filete |
| Ouro | `#B8893B` | 3,1:1 sobre branco; 4,5:1 sobre grafite | só detalhes grandes ou ícones sobre fundo escuro |

## Regras
- Um acento por peça: verde é a cor estrutural, vinho é a cor dos títulos, vermelho é o toque. O ouro entra só como apoio.
- Fundo padrão branco. Creme ou menta só quando o tipo de documento pedir (slides, infográfico).
- Nunca use cores fora desta lista sem perguntar.
